# stupid-code experiments (archive)

Historical variants from the experiment series that produced
[`../stupid-code-system/`](../stupid-code-system/). Kept as a lab
notebook, not for use — the system set supersedes all of them.

## Generations

- **`stupid-code-{a,b,c,d}`** — first generation, four postures: lean
  judgment, exhaustive decision inventory, clean-room sketch+diff,
  personas+judge. All four acquitted a known-stupid planted case;
  posture alone doesn't break a model's sympathetic reading. B's
  inventory was the only mechanism with signal.
- **`stupid-code-v2`, `-v3`** — the rules layer: two-clause definition,
  citation-is-not-a-defense, the operating-regime rule, ~2× build-effort
  allowance, migration-cost-never-defends. v3 convicted the planted case
  with no examples given.
- **`stupid-code-{e,f,g,h}`** — second drastic generation, raced on a
  planted flaw three prior runs had acquitted: the bill (mandatory
  arithmetic — caught it), claim audit (verify every comment — caught
  it, falsified 13 comments), scenario trace (narrated execution —
  caught it decisively), the plant (forced ranking — missed it, best
  novel finds).
- **`stupid-code` + `stupid-code-check`** — the two-agent protocol:
  scanner record + hostile checker attacking acquittals. Doubled
  findings on its validation module with zero annulled convictions;
  became `scanner/` and `checker/` in the system set.
- **`stupid-code-{i,j-defense,k,l,m}`** — third generation:
  - `-i` rewrite/diff — **negative result, retired**: the detector model
    shares priors with the models that wrote the code; it re-invented
    the same flaws and was contaminated through reading tests.
    Convergence never acquits.
  - `-j-defense` — motivated counsel; found real overreach in 4/10
    checked charges. Became `defense/`.
  - `-k` coroner, `-l` burden of proof, `-m` policy court — became
    their system-set counterparts.
- **`stupid-code-{n,o,p}`** — system pieces: courier (cross-module
  dataflow), historian (VCS archaeology), scout (triage). All three
  validated; became `courier/`, `historian/`, `scout/`.

## The lessons that shaped the system set

1. The artifact is the mechanism: every winning variant is a mandatory
   document format that makes one specific evasion unwritable. Personas
   were the weakest lever tested.
2. Search process determines findings more than judgment quality:
   forward reading, incident narration, spec trial, journey tracing,
   and history mining surface disjoint finding classes over the same
   code — hence a bench, not a champion.
3. Asymmetric adversarial review: acquittals hide the value (checker),
   convictions still need auditing (defense); the author's derivation
   alone never yields a pass.
4. Everything the code says about itself is testimony — comments,
   tests, specs — recompute numbers, check sizes after every encoding
   layer.
5. Generation-based detection is structurally unsound when the detector
   shares priors with the authors.
